## Overview

### The challenge

Users should be able to:

- Input mortgage information and see monthly repayment and total repayment amounts after submitting the form
- See form validation messages if any field is incomplete
- Complete the form only using their keyboard
- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

## My process

Challenges
- The input I first made it text but seeing that there would bee many variables to be controlled, I turned to number inputs and only had to deal with the spinners. **Turned into type text with input mode of decimal.
- The ui of the form in, getting to work with the radio buttons. Tried to just add accent but there were messy unwanted styles so I removed default styling.
- Also the states I had to put on a context, I could have putn it on the app since it is the parent of both the components that will use the states.
- If youu do not know that the compound interest formula is not the same as the mortgage formula, you gonna question your knowledge of maths.
- On the states, passing a state as a function will cause an infinite loop.
